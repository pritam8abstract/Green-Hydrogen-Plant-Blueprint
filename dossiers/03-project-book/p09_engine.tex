\subsection{How to run it}
On our Windows laptops, in PowerShell:
\begin{center}
\begin{minipage}{0.9\textwidth}
\ttfamily\fontsize{8.4}{11}\selectfont\color{ink}
git clone https://github.com/pritam8abstract/gh2-india.git\\
cd gh2-india\\
python -m venv .venv; .\textbackslash .venv\textbackslash Scripts\textbackslash Activate.ps1\\
pip install -r requirements.txt\\
python scripts/run\_all.py \hfill\textrm{\itshape\color{ink2} about 15 seconds}\\
pytest -q
\end{minipage}
\end{center}
The random seed is fixed (20261013), so every run gives the same numbers. To change an assumption, edit \texttt{params.py} and rerun; the figures in \texttt{figures/} and the numbers in \texttt{results/results.json} update together.

\begin{plainwords}[Why this matters for the presentation]
When Prof.\ Gopal asks ``where does this number come from?'', the answer is never ``we assumed it''. It is ``\texttt{params.py}, line so-and-so, sourced from this tender result, and here is what happens if it is wrong''. That is the difference between a project report and a project book.
\end{plainwords}
